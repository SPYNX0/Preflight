# Preflight - Addon Launcher

**Launch your flight simulator and all your external addons in one click.**
*Lancez votre simulateur de vol et tous vos addons externes en un clic.*

## ⬇️ Download / Télécharger

👉 **[Latest version / Dernière version](https://github.com/SPYNX0/Preflight/releases/latest)** : download `Preflight-Setup-x.y.z.exe`.


## English

Preflight starts **MSFS 2024** (Microsoft Store or Steam) or **X-Plane 12** (Steam or Laminar Research), detects when you have **spawned** in the aircraft, then launches your addons (ActiveSky, SayIntentions, Volanta, REX…) at the right moment. When you quit the sim, it closes them for you.

- Addons that require administrator rights launch **without the Windows Yes/No prompt** (you confirm once when adding them).
- Three steps: *at sim launch*, *at main menu* or *on spawn*, with optional delays.
- Auto-start with a cancelable countdown, or manual start.
- One button above START switches between MSFS 2024 and X-Plane 12, each with its own addons and profiles.
- Goes to the notification area once the sim is running.
- Interface in 9 languages.
- **Automatic updates**: one click, installed in the background, no Windows prompt.

**Install:** run the setup, click *Yes* on the Windows prompt, done. .NET is included.

> Windows may show *"Windows protected your PC"* the first time (the installer isn't code-signed): click **More info → Run anyway**.

Requirements: Windows 10/11 64-bit, Microsoft Flight Simulator 2024 and/or X-Plane 12.

## Français

Preflight démarre **MSFS 2024** (Microsoft Store ou Steam) ou **X-Plane 12** (Steam ou Laminar Research), détecte quand vous avez **spawn** dans l'avion, puis lance vos addons (ActiveSky, SayIntentions, Volanta, REX…) au bon moment. Quand vous quittez le simulateur, il les ferme pour vous.

- Les addons qui exigent les droits administrateur se lancent **sans le prompt Windows Oui/Non** (une seule confirmation à l'ajout).
- Trois étapes : *au lancement du sim*, *au menu principal* ou *au spawn*, avec délais optionnels.
- Démarrage auto avec compte à rebours annulable, ou démarrage manuel.
- Un bouton au-dessus de LANCER passe de MSFS 2024 à X-Plane 12, chacun avec ses addons et ses profils.
- Se range dans la zone de notification une fois le sim lancé.
- Interface en 9 langues.
- **Mises à jour automatiques** : un clic, installation en arrière-plan, sans confirmation Windows.

**Installation :** lancez l'installeur, cliquez sur *Oui* à l'invite Windows, c'est tout. .NET est inclus.

> Windows peut afficher *« Windows a protégé votre ordinateur »* la première fois (l'installeur n'est pas signé) : cliquez sur **Informations complémentaires → Exécuter quand même**.

Configuration : Windows 10/11 64 bits, Microsoft Flight Simulator 2024 et/ou X-Plane 12.
