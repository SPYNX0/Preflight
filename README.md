# MSFS Starter

**Launch Microsoft Flight Simulator 2024 and all your external addons in one click.**
*Lancez Microsoft Flight Simulator 2024 et tous vos addons externes en un clic.*

## ⬇️ Download / Télécharger

👉 **[Latest version / Dernière version](https://github.com/SPYNX0/MSFS-Starter/releases/latest)** — download `MSFSStarter-Setup-x.y.z.exe`.

---

## English

MSFS Starter starts MSFS 2024 (Microsoft Store or Steam), detects when you have **spawned** in the aircraft, then launches your addons (ActiveSky, SayIntentions, Volanta, REX…) at the right moment. When you quit the sim, it closes them for you.

- Addons that require administrator rights launch **without the Windows Yes/No prompt** (you confirm once when adding them).
- Two steps: *at sim launch* or *on spawn*, with optional delays.
- Auto-start with a cancelable countdown, or manual start.
- English / French interface.
- **Automatic updates**: the app tells you when a new version is available, one click to install.

**Install:** run the setup, click *Yes* on the Windows prompt, done. .NET is included.

> Windows may show *"Windows protected your PC"* the first time (the installer isn't code-signed): click **More info → Run anyway**.

Requirements: Windows 10/11 64-bit, Microsoft Flight Simulator 2024.

## Français

MSFS Starter démarre MSFS 2024 (Microsoft Store ou Steam), détecte quand vous avez **spawn** dans l'avion, puis lance vos addons (ActiveSky, SayIntentions, Volanta, REX…) au bon moment. Quand vous quittez le simulateur, il les ferme pour vous.

- Les addons qui exigent les droits administrateur se lancent **sans le prompt Windows Oui/Non** (une seule confirmation à l'ajout).
- Deux étapes : *au lancement du sim* ou *au spawn*, avec délais optionnels.
- Démarrage auto avec compte à rebours annulable, ou démarrage manuel.
- Interface en français / anglais.
- **Mises à jour automatiques** : l'app vous prévient quand une nouvelle version sort, un clic pour l'installer.

**Installation :** lancez l'installeur, cliquez sur *Oui* à l'invite Windows, c'est tout. .NET est inclus.

> Windows peut afficher *« Windows a protégé votre ordinateur »* la première fois (l'installeur n'est pas signé) : cliquez sur **Informations complémentaires → Exécuter quand même**.

Configuration : Windows 10/11 64 bits, Microsoft Flight Simulator 2024.
